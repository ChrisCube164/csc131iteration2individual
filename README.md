# csc131iteration2individual

For Iteration 2 for our project, we implemented a SQLite database to our server. By the time the assignment was announced, most of the SQL database had been completed already. With Cloudflares implementation, it wasn't too hard to get something working. We just needed the schema.sql file and keys to get something basic working. Attaching the database to our login prompt made it so that when the user creates an account, we can store their information for retrieval when logging in. The SQL commands themselves were pretty easy due to the SQL language being mostly plain English. I helped provide an outline of what needs to be done for this iteration of the project, but since we already had made a database, the only real thing to do was to work on filling out the questions on the assignment and research alternative methods of databases like No-SQL. The next real step we need to take is working on processing the data. Since the user can log in, we need to flesh out adding calories and steps. Our goal was to have a week by week showing of the user's progress throughout the week using a SQLite table that only holds the days of the week for that user. And of course working on simple, easy to read UI is also important to streamline things. For testing we will most likely implement a sample user with everything filled out.
